# Headline or Hype?

A basic Three.js hackathon prototype for **Headline or Hype? — compare headlines with evidence**.

## Gameplay

- Walk around a stylised data-centre environment with **WASD**.
- A faceless NPC walks toward the evidence terminal rather than being the player.
- Press **E** near the terminal to open the evidence interface.
- Read a headline and estimate the renewable-energy share with the slider.
- Submit the estimate to reveal the fictional true value and supporting evidence.
- Continue to the next headline.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Notes

This is intentionally an asset-free template: the data centre, wind turbines, NPC, terminal and UI are generated with Three.js/CSS. Replace the sample evidence with verified sources before presenting real-world claims.
